Спроси уточняющие вопросы перед началом работы

Создай класс интегратора(Hashtable, AVLTree с синхронизующимися копиями каждого в DoublyLinkedList). Однако в Hashtable, AVLTree будут хранится индексы из  Hashtable, AVLTree вместо самих элементов
Когда у него вызывается функция создания-удаления-запроса-изменения записей, он их выполняет для всех указанных классов.
Требования - 
Нужно изменить место хранения записей из ОБОИХ структур данных в ОТДЕЛЬНЫЕ инстансы уже реализованного двухсвязного списока(Сам doublylinkedlist менять на stl нельзя, то есть нельзя использовать vector и мы работаем с именно двухсвязным списком с репозитория, но можно добавлять функционал) для каждой структуры данных, итого 2 двухсвязных списка. Структуры(Hashtable and AVLTree) данных должны хранить индекс элемента(НЕ УКАЗАТЕЛЬ) в данном списке. При удалении из середины  ячейка соответствующего двухсвязного списка перезаписывается на последнюю ячейку(после чего последняя ячейка удаляется), если это последняя ячейка то просто удаляем и обновляем наши указатели (указатели на tail и head)  
Когда через интегратор пытаемся удалить запись в первой таблице (хештаблица), проверяем есть ли записи с такими же ключевым полем во второй таблице (дерево), для того чтоб их так же удалить.
Когда через интегратор пытаемся добавить запись во второй таблице (дерево), проверяем существует ли запись с таким же ключевым полем в первой таблице (хештаблица), для того чтоб выдать ошибку о неправильной вставке.

Тесты должны будут тестировать новый функционал.
